# Contributing to Luna Rae

Thank you for your interest in contributing to Luna Rae.

## Mission

Luna Rae is being developed to create an intelligent AI assistant that helps people accomplish real-world tasks through automation, organization, and practical assistance.

## How to Contribute

We welcome contributions that:

- Fix bugs
- Improve documentation
- Add useful features
- Improve performance
- Increase security
- Enhance accessibility

## Before You Begin

Please:

1. Fork the repository.
2. Create a new branch for your changes.
3. Keep commits focused and well documented.
4. Test your changes before submitting.
5. Submit a Pull Request describing what you changed and why.

## Code Style

- Write clean, readable code.
- Comment complex logic when appropriate.
- Keep changes focused on one feature or fix.

## Reporting Issues

If you discover a bug or security issue, please open an Issue with steps to reproduce the problem.

## Community

Please be respectful, constructive, and professional. We are building technology that helps people, and collaboration should reflect that goal.

Thank you for helping shape Luna Rae.
